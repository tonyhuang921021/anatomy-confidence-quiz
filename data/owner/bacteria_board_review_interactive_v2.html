複習路徑與使用方式

本表以國考題幹常見線索為主軸，依檢驗定位、疾病定位、比較定位與單菌收尾四層複習。

1. 檢驗定位Gram / 球桿 / catalase / oxidase / lactose / 特殊培養，是最有效率的初步排除法。
2. 疾病定位肺炎、腹瀉、腦膜炎、STI、皮膚傷口、院內感染等題幹場景可用來反推病原。
3. 比較定位同一群菌以表格並列：Staph 三兄弟、Strep 六群、Clostridium 四大、E. coli 六型。
4. 單菌收尾每張菌卡固定六格：一句話、鑑別、培養、毒力、疾病、治療陷阱。

快速總覽（20 分鐘）

  1. 鑑別樹
  2. 培養基表
  3. 易混陷阱
  4. ★★★/★★★★ 菌卡

完整複習（1–2 小時）

  1. 疾病導向快速瀏覽
  2. 比較表按「實驗室 → G+ → G− → 疾病題幹」
  3. 自測模式抽卡

平時複習

  1. 依分類讀菌卡
  2. 錯題菌可用搜尋回到比較表
  3. agar、毒素、疫苗題直接回專區
版面結構：總表集中於「比較表」區；單菌細節以卡片呈現，點開後查看完整內容。

鑑別樹

看到檢驗線索時，可先依此區逐步定位病原。

疾病/暴露導向

每個情境大標皆可點開查看完整表格；表格中的菌名可再點開菌卡。

使用方式：主頁只保留情境大標；點開任一大標後，在彈窗內查看完整表格與細分線索。表格中的菌名仍可再點開菌卡。

培養基 / 特殊培養速查

Agar 與特殊培養條件常作為題幹線索，本區集中整理常考培養基。

比較表套件

依主題切換比較表：實驗室、G+、G−、疾病題幹、毒素、疫苗與治療。

易混陷阱

常見混淆點集中整理，適合考前快速複習。

菌卡索引

搜尋與分類可同步過濾；每張卡片可點開查看完整菌卡。

自測模式

隨機抽取菌卡，以題幹線索練習快速辨認病原。

Random card
整理用途：醫師國考一階複習。治療欄為考試/概念整理，不作為臨床處方；臨床請依最新指引、藥敏與院內 antibiogram。
