# PDF font

Noto Serif TC Regular, official Traditional Chinese subset OTF.

Source: https://github.com/notofonts/noto-cjk/blob/main/Serif/SubsetOTF/TC/NotoSerifTC-Regular.otf
License: SIL Open Font License 1.1; see OFL.txt.

The unmodified font is served locally and loaded only when generating a PDF. The complete OpenType font is embedded to preserve reliable CJK rendering across PDF readers; exported files include about 6.9 MB of font data.
