# Iansui homepage subset

`iansui-home.woff2` is a small homepage-only subset of [Iansui](https://github.com/ButTaiwan/iansui), licensed under the SIL Open Font License 1.1. The license text is included as `OFL-Iansui.txt`.

It contains only `國考刷題先寫幾題，看看還記得多少。`. If the fixed homepage copy changes, regenerate the subset from `Iansui-Regular.ttf` with the exact new characters. Dynamic tone and statistics copy deliberately uses the normal interface font so it cannot fall back for missing glyphs.
